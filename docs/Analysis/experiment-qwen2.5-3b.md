## Методика расчёта

**Kendall τ** — коэффициент ранговой согласованности двух полных перестановок одного и того же набора из n тестов:

τ = (C − D) / (n(n − 1)/2),

где C — число согласованных пар, D — число несогласованных пар (попарное сравнение позиций в эталоне и в прогоне). Диапазон: от −1 до 1.

**LCS (%)** — доля тестов эталона, сохранённых в относительном порядке как подпоследовательность прогона:

LCS% = |LCS(эталон, прогон)| / n × 100.

Пороги из ПЗ: τ > 0 и LCS > 50%.

## Выводы

- **Kendall τ.** Среднее значение по 30 прогонам (qwen2.5:3b) составило 0.287 (min -0.4, max 0.6, median 0.4). Порог τ > 0 выполнен в 24 из 30 прогонов (80%). Средняя согласованность с эталоном положительна — порядок LLM в целом совпадает с data-driven эталоном по провалам.
- **LCS.** Средняя доля сохранённого относительного порядка — 64% (min 40%, max 80%, median 60%). Порог LCS > 50% выполнен в 28 из 30 прогонов (93.3%). Большинство прогонов сохраняет более половины эталонной последовательности.
- **Сравнение с «Анализ результатов 2.md».** Ранее усреднённая метрика «Точность 64%» совпадает с округлённым средним LCS (64%; расхождение +0 п.п.), что подтверждает эквивалентность LCS% и прежней шкалы «N из 5».
- **Практический вывод.** При фиксированном наборе из пяти smoke-тестов B2C двухэтапное LLM-ранжирование Triage с моделью qwen2.5:3b даёт согласованность с эталоном, упорядоченным по истории провалов; метрики τ и LCS применимы в ПЗ для подтверждения качества порядка выполнения тестов.
