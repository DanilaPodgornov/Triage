Prompt writing guide

Prompts are model-specific. Keep mandatory placeholders and JSON response schemas unchanged.

Weights prompt

  • Keep the {testCaseData} placeholder — the app injects test metadata there.
  • Response JSON must contain exactly eight keys: priority, status, labels, executionsCount, failuresCount, failedExecutionsRatio, lastExecutionStatus, executionTime.
  • Each value is 0–1 and all eight must sum to exactly 1. Reply with JSON only.
Respond with JSON only, matching this schema exactly:
{
  "priority": 0.0,
  "status": 0.0,
  "labels": 0.0,
  "executionsCount": 0.0,
  "failuresCount": 0.0,
  "failedExecutionsRatio": 0.0,
  "lastExecutionStatus": 0.0,
  "executionTime": 0.0
}

AI sort prompt

  • Keep the {testCasesJson} placeholder — the app injects the ranked test list there.
  • Response JSON must include suggestedTestCycleName and a tests array with every input key exactly once.
  • Each aiSort is 0–1; all values must sum to exactly 1. Tests with failed executions must rank higher.
Respond with JSON only, matching this schema exactly:
{
  "suggestedTestCycleName": "short descriptive cycle name",
  "tests": [
    { "key": "KEY1", "aiSort": 0.0 }
  ]
}
